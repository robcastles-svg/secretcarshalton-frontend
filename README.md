# secretcarshalton-frontend

Next.js front end for secretcarshalton.com. WordPress (on SiteGround) stays
in place as the headless CMS backend — this app reads content from its
REST API and renders it independently. Deployed on Vercel.

## Status

Skeleton only — proving the GitHub → Vercel deploy pipeline. Real pages
(posts, events, directory) come next.

## Local dev

```
npm install
npm run dev
```
